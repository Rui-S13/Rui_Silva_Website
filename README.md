# Rui_Silva_Website

Website pessoal desenvolvido no âmbito da formação UpSkill, com o objetivo de apresentar o meu percurso, experiência, competências, projetos e interesses.

## Links

* [GitHub Pages](https://rui-s13.github.io/Rui_Silva_Website/)
* [Google Stitch](https://stitch.withgoogle.com/projects/7265500087741932118)


## Sobre o projeto

Este projeto consiste num website pessoal de uma página, desenvolvido como exercício prático de HTML e CSS.

O website inclui:

* Apresentação pessoal
* Experiência académica e profissional
* Competências técnicas
* Projetos desenvolvidos
* Interesses pessoais
* Contactos
* Design responsivo para desktop e dispositivos móveis

## Tecnologias utilizadas

* HTML5
* CSS3

## Funcionalidades

* Navegação entre as diferentes secções da página
* Menu adaptado para dispositivos móveis
* Submenu para a secção de interesses
* Layout responsivo
* Apresentação de progresso da leitura através de um elemento `<progress>`
* Separadores entre livros e filmes utilizando apenas HTML e CSS
* Formulário para introdução de comentários
* Botão para voltar ao topo da página através de uma âncora HTML e CSS
